# XRP Studio

Fork of [Open-STEM/XRPWeb](https://github.com/Open-STEM/XRPWeb): web IDE for the XRP robot
(Blockly blocks + Python/MicroPython). Fork goals: work without internet, MakeCode-style blocks,
a simple UI for kids, Spanish first; desktop and Android tablet.

## Commands

- `npm install` (not `npm ci`: upstream's `package-lock.json` is out of sync; do not commit
  lockfile changes unless dependencies are added)
- `npm run dev` / `npm run dev:offline` → http://localhost:3000 (Chrome or Edge; Web Serial does
  not exist in Firefox/Safari)
- `npm run build` / `npm run build:offline` → `dist/` (may need
  `NODE_OPTIONS=--max-old-space-size=8192`)
- `npx vitest run` (single run; `npm test` stays in watch mode)
- `npm run lint`

## Architecture

- Entry: `src/main.tsx` (providers, i18n) → `src/App.tsx` → `src/components/xrplayout.tsx`
  (tab layout with flexlayout-react) and `navbar.tsx` (menus and Run button).
- Singleton managers in `src/managers/` talk through events (`AppMgr.emit/on`, mitt):
  `connectionmgr` (USB/Bluetooth), `commandstoxrpmgr` (XRP REPL), `editormgr` (editor sessions),
  `pluginmgr`.
- Connection: `src/connections/` (Web Serial and Web Bluetooth).
- Blocks: `src/components/blockly.tsx` (workspace, theme, toolbox) and `src/components/blockly/`
  (XRP block definitions and Python generator).
- Python editor: `MonacoEditor.tsx` + `lsp-client.ts` (Pyright in a web worker, offline).
- i18n: `src/utils/i18n/locales/{en,es}/` (i18next) and `src/utils/blockly-locales.ts`.
- Firmware and libraries: `public/` (manifests generated by `scripts/gen-firmware-manifests.mjs`).
- Network services: Google login/Drive (`src/services/google-*.ts`, `src/widgets/login.tsx`),
  AI chat (`src/components/chat/`, hidden by default: `?aibuddy=1`), telemetry in
  `connectionmgr.ts` (`IDSet`).

## Offline mode

`VITE_OFFLINE=true` (or `--mode offline`, which loads `.env.offline`). Flag in
`src/utils/offline.ts` (`isOfflineBuild`). With the flag: the Google Identity script is not
loaded and no client ID is requested, the AI chat is hidden, and telemetry is not sent.

Local projects (MakeCode-style, no login): `src/services/local-drive.ts` implements the
`GoogleDriveService` interface on top of IndexedDB, and `src/widgets/local-session.tsx` signs in
to it automatically on startup. All existing Drive code (file tree, open, save, autosave, Run)
then uses the browser unchanged. `AppMgr` picks the service based on the flag.

Offline text overrides live in `src/utils/i18n/locales/{en,es}/offline.json` and are merged over
the base translations only in offline builds (Drive wording → "My projects", Help links marked
"online"). Driver installation is allowed offline. With the robot connected the tree shows local
projects, not the XRP's internal files.

## Conventions

- Everything in the repo is in English: code, identifiers, comments, tests, docs, commit
  messages and branch names. Spanish lives only in `src/utils/i18n/locales/es/`.
- User-facing text always goes through i18n (en and es).
- Comments: documentation comments only (`/** */` on modules, classes, functions). No inline
  `//` comments in code we add; put the explanation in the doc comment. Leave upstream comments as
  they are.
- Minimal changes to upstream files: prefer new files, flags and small hooks over rewrites.
  Do not delete upstream code; disable it behind a flag.
- Pull upstream changes: `git fetch upstream && git merge upstream/main` on `main`.
- One branch per phase/task.
- Prettier: 4 spaces, single quotes, 100 columns. Import aliases: `@/`, `@components/`,
  `@utils/`, `@connections/`, `@assets/`.
- License GPL: the fork stays GPL.
