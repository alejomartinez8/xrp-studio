# Novedades de XRP Studio

## Versión 0.2.0

Un aspecto nuevo y un editor de Python más fácil.

### Aspecto
* Un aspecto nuevo inspirado en VS Code, con los temas Light+ y Dark+, paneles redondeados y una barra de iconos más delgada.
### Editor
* Editor de Python: una caja de fragmentos de código listos para usar, con categorías de colores, explicaciones, búsqueda y arrastrar y soltar.
* Los archivos de bloques guardados con una versión anterior ahora muestran bien su código Python.
### Paneles
* El panel Terminal ahora tiene un botón para cerrarlo.
### Por dentro
* Código y pruebas más ordenados.

## Versión 0.1.0

Primera versión de XRP Studio, basada en XRPWeb.

* Funciona sin internet: instálalo como app y abre sin conexión, con bloques, Python, firmware y controladores.
* Mis proyectos: tus programas se guardan solos en tu dispositivo, con Papelera y Archivados.
* Cuentas y sincronización: entra con Google para guardar tus proyectos en tu cuenta y compartir una tableta.
* Disponible en varios idiomas, con un aspecto amigable y colorido y temas claro y oscuro.
* Un nuevo editor de bloques con búsqueda y un editor de Python con colores y sugerencias.
* Librerías actualizadas para que todo sea rápido y seguro.
